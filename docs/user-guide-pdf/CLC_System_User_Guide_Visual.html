操作说明

1. 登入系统

1.输入主席或老师给予的账号与密码。
2.请勿把账号分享给其他人。
3.登入后会进入 Dashboard 仪表盘。
CHMS1 Chinese Language Club System
操作说明

2. Dashboard 仪表盘

1.查看待完成任务、本月活动、请假、公告和系统动态。
2.快捷入口会根据身份自动显示。
3.普通会员不会看到管理成员入口。

操作说明

3. 任务页面 Tasks

1.管理层可发布任务和查看成员任务表现。
2.普通会员只看自己相关团队与被分配的任务。
3.任务完成后会通知老师、主席、副主席和发布者。

操作说明

4. 请假申请 Leave

1.选择请假类型、日期并填写原因。
2.请先把签名请假信上传到指定 Google Drive。
3.把文件分享链接贴入系统保存记录。
CHMS1 Chinese Language Club System
操作说明

5. 行事历 Calendar

1.蓝色是学会活动，绿色是内部会议。
2.活动与会议会在 7 天、3 天、1 天前提醒。
3.红色截止日期由任务提醒规则处理。
CHMS1 Chinese Language Club System
操作说明

6. 账号管理 Members

1.只有召集老师、指导老师、主席、副主席可以管理成员。
2.可新增、修改、停用或启用账号。
3.文书不会看到管理成员入口。

7. 设置与 PWA 推送

1.iPhone 必须用 Safari 加入主屏幕后开启推送。
2.Android / Desktop 可用 Chrome 或 Edge 开启通知。
3.如果收不到通知，先回设置重新启用推送。
