## 已修复的问题

1. **注册提权**：注册触发器原先信任客户端的 `raw_user_meta_data.role`，可被用于申请管理角色。现在新注册账号固定为 `ordinary_member` 且未启用，由已授权管理员再启用和分配角色。已有账号不变。
2. **未启用账号读取内部资料／上传文件**：为内部业务表及应用文件上传增加有效会员限制。公开文章、公开头像、公开网站图片的读取不变。
3. **旧提醒接口没有认证**：任务到期、活动会议提醒现在要求 POST 和有效服务器凭证。同步改好原有 cron 请求头，不改变时间表。
4. **任务字段越权**：任务被指派人只能更新进度，不能自行改截止日期、负责人、任务内容或归档标记。完成时间由服务器确定，既有管理者编辑权保留。
5. **通知内容篡改**：浏览器只能更新自己通知的 `read_at`，不能直接修改通知标题、正文、收件人或插入通知；可信业务 RPC 与发送接口仍可创建通知。
6. **推送请求滥用**：增加请求体类型、字段、UUID、文本长度、批量数量、URL 和 3 MB 请求体限制；普通会员调用按账号每分钟最多三十次，可信服务器定时任务不受此会员限流影响。
7. **CORS 和错误暴露**：自有推送接口使用明确来源名单，拒绝未知网站；返回通用错误，不把数据库／FCM 的详细异常送给浏览器。内部归档接口移除 CORS 通配符。
8. **安全响应头**：新增 CSP、禁止嵌入、nosniff、Referrer-Policy、Permissions-Policy、HSTS。需部署 Vercel 后才生效。CSP 保留 React 所需的内联样式，但不允许内联脚本或 eval。
9. **依赖修补**：路由保持 7.x，Firebase 保持原主版本，针对传递依赖做兼容修补，没有使用 `npm audit fix --force`。本轮修补后 npm audit 无已知公告漏洞，这不等于所有漏洞不存在。
